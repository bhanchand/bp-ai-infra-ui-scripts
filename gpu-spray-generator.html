Comprehensive DWS & Multi-Region Capacity Guide

1. The Core Problem: Regional Allocation Volatility

Leading-edge AI accelerators (NVIDIA H100 SXM5, H200, B200) are heavily oversubscribed across public clouds. Synchronous creation calls (gcloud compute instances create) almost invariably return ZONE_RESOURCE_POOL_EXHAUSTED.

2. How DWS Flex-Start Solves This

Google Cloud's Dynamic Workload Scheduler (DWS) introduces queued provisioning (--provisioning-model=FLEX_START). Instead of an instant reject, DWS enqueues your instance request for up to 2 hours (--request-valid-for=7200s). You are billed $0 while waiting.

By queuing across 16+ candidate zones simultaneously, your chances of catching a capacity release jump to over 90% during standard off-peak or shift-change windows.

3. Preventing Duplicate Billing: The Watcher Engine

If 3 of your 16 queued requests grant capacity around the same time, you would be charged for 3 instances. The generated watcher loop queries active instance states every 30 seconds. The instant the first instance transitions to RUNNING, the watcher triggers background gcloud compute queued-resources delete calls for all remaining losing queues.

4. State Persistence via GCS-FUSE

Because you cannot predict which zone will grant capacity, you must decouple data from local disks. Auto-mounting a Cloud Storage bucket via Cloud Storage FUSE at /gcs allows training checkpoints, datasets, and scripts to be immediately available regardless of which zone boots first.

Automated GPU Quota & Capacity Management

Cloud Quotas API + Terraform

Automate capacity requests, programmatic quota approvals, and resilient multi-region fallback handling.

API: cloudquotas.googleapis.com
1. Pre-Flight Headroom Gate

Before submitting parallel sprays, the script queries limit - usage for target metrics (e.g. NVIDIA_H100_GPUS) across candidate regions. Zero-quota regions are pruned gracefully without failing the entire run.

2. Programmatic Quota Requester

Use Google's modern Cloud Quotas API (gcloud beta quotas preferences create) or the bundled ./scripts/request-gpu-quota.sh to request capacity across multiple regions in one step.

3. Future Reservations (Calendar)

For mission-critical deadlines or multi-node training, automate scheduling guaranteed hardware windows using DWS Calendar-Mode (gcloud compute future-reservations create).
