OS Login Access Control & Required IAM Roles Guide

GCP Guide

When OS Login is enabled, SSH access is centrally managed via Google Cloud IAM rather than metadata public keys. To grant an engineer, researcher, or team group access to the cluster nodes, assign the following roles:

Standard User Access No sudo
roles/compute.osLogin

Allows standard SSH login to VM instances without root/sudo capabilities.

Administrator Access Root / Sudo
roles/compute.osAdminLogin

Grants full administrative SSH login with passwordless sudo root privilege.

Service Account User Required
roles/iam.serviceAccountUser

Crucial: Must be bound on the instance's service account to authorize the login session.

External Organization User Contractors
roles/compute.osLoginExternalUser

Required if collaborator's Google account is outside the GCP Organization domain.
