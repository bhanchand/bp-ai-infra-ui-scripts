🚀 Vertex AI Colab Enterprise Walkthrough

Detailed guide for admins and researchers to deploy and connect to interactive GPU notebooks.

Step 1: Run the Deployment Script

Open Google Cloud Shell and run the generated colab-workbench-setup.sh script. It creates template msu-h100 with the specified GPU, disk size, and network properties.

Step 2: Open Colab Enterprise Console

Navigate to:
https://console.cloud.google.com/vertex-ai/colab/notebooks

In the top right region picker, select us-west1.

Step 3: Launch Runtime

Click "Create runtime" or open any notebook and select "Connect to custom runtime". Choose the template created in Step 1. The H100 slice boots in ~60-90 seconds.

Step 4: Cost Control & Idle Shutdown

Colab Enterprise includes built-in idle termination:

  • Configure Idle Shutdown to 30 or 60 minutes to prevent researchers from leaving idle H100 instances running overnight.
  • Notebook code and output cells are stored in Google Drive or Cloud Storage, preserving state across shutdowns.
Step 5: Required IAM Roles

Ensure researchers have the following project roles:

  • roles/aiplatform.user
  • roles/notebooks.admin
  • roles/compute.networkUser
Step 6: Quota Preflight

Verify in Cloud Console Quotas that your project has:

  • NVIDIA_H100_GPUS >= 1 in target region
  • CPUS >= 26 in target region
