Slurm Cluster Integration (Cluster Toolkit)

Configure your Slurm partition nodesets to automatically consume DWS Flex reservations when granted:

nodeset.yaml snippet 
nodeset_name: a3-mega-nodeset
node_count_dynamic_max: 32
node_conf:
  MachineType: a3-megagpu-8g
  # Enables consumption of any matching DWS reservation:
  reservation_affinity:
    consume_reservation_type: "ANY_RESERVATION"
  # Or target specific reservation name:
  # reservation_affinity:
  #   consume_reservation_type: "SPECIFIC_RESERVATION"
  #   specific_reservations:
  #     - key: "compute.googleapis.com/reservation-name"
  #       values: ["res-dws-uscentral1b-01"]
  • Slurm jobs queued with sbatch -p a3-mega remain queued until the reservation enters READY state.
  • Once granted, nodes spawn in <90 seconds and run for the full max duration.

GKE Cluster Nodepool Integration

Attach a Google Kubernetes Engine nodepool to consume the created DWS Flex reservation:

gcloud container command 
gcloud container node-pools create h100-dws-pool \
  --cluster=my-ai-cluster \
  --zone=us-central1-b \
  --machine-type=a3-megagpu-8g \
  --enable-autoscaling --min-nodes=0 --max-nodes=8 \
  --reservation-affinity=specific \
  --reservation=res-dws-uscentral1b-xxxx \
  --enable-gvnic \
  --accelerator=type=nvidia-h100-80gb,count=8
  • Autoscaler scales nodes from 0 to max when Kubernetes Pods with matching tolerations and nodeSelectors are scheduled.
  • Kueue or Ray on GKE handles job queueing until DWS confirms reservation capacity.

🛠️ DWS Flex Reservation CLI Quick Reference

Useful commands to monitor, describe, and clean up reservations across zones:

List All DWS Reservations 
gcloud compute reservations list \
  --project=$PROJECT_ID \
  --filter="specificReservation.dwsFlex.enabled=true" \
  --format="table(name,zone,status,specificReservation.count,specificReservation.instanceProperties.machineType)"
Check Reservation Status & Details 
gcloud compute reservations describe RES_NAME \
  --zone=ZONE \
  --project=$PROJECT_ID \
  --format="yaml(status,specificReservationRequired,specificReservation)"
Delete a Specific Reservation 
gcloud compute reservations delete RES_NAME \
  --zone=ZONE \
  --project=$PROJECT_ID \
  --quiet
Delete All Expired / Unused Reservations 
gcloud compute reservations list \
  --project=$PROJECT_ID \
  --filter="status!=READY" \
  --format="csv[no-heading](name,zone)" | while IFS=, read name zone; do
    gcloud compute reservations delete "$name" --zone="$zone" --quiet &
  done

Automated GPU Quota & Capacity Management

Cloud Quotas API + Terraform

Automate capacity requests, programmatic quota approvals, and resilient multi-region fallback handling.

API: cloudquotas.googleapis.com
1. Pre-Flight Headroom Gate

Before submitting reservation creations, the script queries limit - usage for target metrics across candidate regions. Zero-quota regions are pruned gracefully without failing the entire run.

2. Programmatic Quota Requester

Use Google's modern Cloud Quotas API (gcloud beta quotas preferences create) or the bundled ./scripts/request-gpu-quota.sh to request capacity across multiple regions in one step.

3. Future Reservations (Calendar)

For mission-critical deadlines or multi-node training, automate scheduling guaranteed hardware windows using DWS Calendar-Mode (gcloud compute future-reservations create).
